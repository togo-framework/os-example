# os-example — docs

Documentation for the togo OS desktop demo.

- **The `os` plugin:** https://github.com/togo-framework/os
- **Start your own:** `togo new <app> --frontend os`
- **Add an app:** `togo make:os-app <name>`

See the repository [README](../README.md) for the overview and the
[`plugins/`](../plugins) directory for the example OS apps (Settings, Notes, Weather).
